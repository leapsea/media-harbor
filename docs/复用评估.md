# Media Harbor · 参考项目与依赖复用

开发前检查了两个参考项目的公开许可证和架构：

| 项目 | 许可证 | 技术/接口 | V1 采用方式 |
| --- | --- | --- | --- |
| [gdluxx](https://github.com/gdluxx/gdluxx) | GPL-2.0 | Svelte 应用，任务、规则、配置编辑、版本管理 | 参考产品交互；没有复制源码或组件 |
| [gallery-dl-server](https://github.com/qx6ghqkz/gallery-dl-server) | MIT | Python Web 服务，gallery-dl/yt-dlp 集成 | 参考引擎与 Docker 集成方式；没有复制源码 |

两者的应用层与指定 Go + Vue 栈不同。直接依赖其服务 API 将引入第二套应用与持久化，因此本项目自行实现应用层，复用官方引擎的标准命令行与 JSON 元数据协议。

gallery-dl 是 GPL-2.0 下载引擎；yt-dlp 使用 Unlicense，并包含其他组件的许可证声明；FFmpeg 许可证取决于构建选项。它们作为独立进程安装在镜像中，应用没有复制或链接其代码。发布镜像时应保留软件包原有许可证和相应分发声明。本项目尚未指定应用自身许可证。

接口依据：

- [gallery-dl 选项](https://github.com/mikf/gallery-dl/blob/master/docs/options.md)：JSON 扫描、Cookie、精确输出目录和文件过滤。
- [gallery-dl Instagram 提取器](https://github.com/mikf/gallery-dl/blob/master/gallery_dl/extractor/instagram.py)：owner_id、post_id、num、post_url 和日期。
- [yt-dlp 官方文档](https://github.com/yt-dlp/yt-dlp)：元数据 JSON、字幕、评论、音频、下载格式和 JS runtime。使用 Node 与 `yt-dlp[default]` 提供的 EJS 支持 YouTube。
- [Alpine FFmpeg 包](https://pkgs.alpinelinux.org/package/v3.23/community/aarch64/ffmpeg)：V1 固定 `8.0.1-r1`，与 Python 包独立管理。
