# v1.0.0 实现内容

Media Harbor 提供 YouTube、Instagram 的任务管理、内容下载、文件整理与归档，通过 Web 界面操作，使用 Docker Compose 部署。

## 任务创建与执行

- 支持博主主页与单个视频、帖子地址，根据地址识别执行方式并解析目录名称。
- 主页任务保存后，由首次手动全量初始化、增量扫描或补全下载启动处理与周期。默认周期为每六小时，支持间隔与 Cron 设置。
- 详情任务保存后立即执行一次。
- 任务管理按配置汇总为一行，展示平台、状态、下载进度、最近更新和日志。
- 支持编辑、删除、取消、失败重试、暂停与恢复定时执行。

## 扫描与下载调度

- 扫描逐条交付媒体，下载与解析同时进行。采用有界队列，消费不足时生产等待。
- 按平台分别控制下载并发，默认 YouTube 2 个内容、Instagram 10 个内容；音频、字幕、评论等产物归属于对应内容。
- 根据内容索引识别重复内容，普通扫描只为新增内容安排下载。
- 任务及内容状态持久化，服务重启后重新调度未完成任务，复用已取得的文件。
- 系统设置中的调试开关支持限制处理条数，默认关闭，开启时可配置数量。

## 下载产物

- YouTube 默认下载最高画质 MP4，并额外保存 m4a 音频。
- 支持字幕、自动字幕、评论、缩略图、元数据、独立音频下载与本地音频提取。
- YouTube 初始设置启用字幕、评论、缩略图、元数据及额外音频；字幕语言为 `zh.*,en`，任务内部片段并发为 6。
- 任务可覆盖全局下载选项。
- Instagram 支持帖子媒体下载和博主头像展示。
- 已配置的 Cookie 自动用于扫描和下载；编辑器接受浏览器 Cookie 请求头及 Netscape 文本。

## 补全与文件整理

- 补全下载复用同一内容已有的视频、音频、字幕，只下载当前选项需要的缺失产物。
- 手动补全刷新所选元数据和评论，更新已有元数据文件。
- 默认目录模板为 `{platform}/{directory_name}/{year}/{month}{day}/{filename}`。
- 日期默认使用上传或发布时间，缺失时使用任务创建日期，按本地时区计算；日期来源可在设置中调整。
- 支持自动归档、目录状态检测及归档重试。归档完成后记录目标路径，跨文件系统移动在复制成功后删除源文件。

## 下载历史与日志

- 下载历史展示实际产物标签及文件名，评论与元数据关联同一个 JSON 文件。
- 支持复制视频、音频所在文件夹的完整路径。
- 清空历史只移除展示记录，保留真实文件、下载索引与任务，维持扫描去重和文件复用。
- 日志记录时间、阶段、媒体标识、发现与新增数量、重复数量、耗时及错误；等待扫描时持续输出进度。
- 下载进度日志按时间合并，日志窗口内部滚动，支持选中窗口内的全部日志。
- 存储管理展示日志与工作缓存占用，支持清空日志、清理已完成及无关联任务缓存，保留未完成任务的工作文件。

## 界面与设置

- 页面包括总览、任务管理、下载历史、系统设置。
- 表单采用紧凑行布局，支持桌面与竖屏；操作反馈统一使用 Toast。
- 支持简体中文、英文、印地语、俄语和日语，语言在系统设置中切换并保存。
- 总览最新下载默认展示 3 条，任务管理和下载历史默认每页 20 条，均可调整。
- 新任务默认自动归档按首次初始化的归档目录挂载状态设置；未挂载时禁用并取消勾选。
- 系统设置按下载、目录规则、Cookie、引擎、界面、存储、调试分类。

## 部署与发布

- Docker 支持 amd64 与 arm64，数据、下载、归档、日志分别挂载。
- GitHub Actions 执行后端、前端与容器验证，通过后发布 GHCR 镜像。
- 版本标签发布对应版本镜像；正式版本同时更新 `latest`。
- 每六小时检查 gallery-dl、yt-dlp 稳定版本及 Alpine 3.23 两个架构共同可安装的 FFmpeg 版本。
- 依赖变化时自动增加补丁号，合并多个依赖更新；验证与镜像发布成功后保存版本清单及标签。
- 项目版本与固定依赖统一保存在 `internal/config/release.json`，镜像构建注入应用显示版本。
