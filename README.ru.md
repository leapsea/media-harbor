# Media Harbor

Скачивайте контент YouTube и Instagram на своё устройство, раскладывайте файлы по авторам и датам и получайте новые публикации из профилей.

## Возможности

- Разовая загрузка видео или поста и проверка профилей по расписанию.
- YouTube: MP4 в максимальном качестве и дополнительное аудио m4a; выбор субтитров, комментариев, миниатюр и метаданных.
- Пропуск уже скачанного. Дозагрузка использует существующие файлы, получает недостающие и обновляет выбранные комментарии и метаданные.
- Статус, прогресс, журналы и история в одном интерфейсе; отмена, повтор и продолжение после перезапуска.
- Организация и архивирование файлов. Интерфейс доступен на китайском, английском, хинди, русском и японском.

## Запуск

### Вариант 1: Скачать готовый образ (рекомендуется)

Установите Docker; исходники не нужны. После первой публикации образа выполните:

```sh
docker pull ghcr.io/leapsea/media-harbor:latest
mkdir -p data downloads archive logs
```

В Linux перед запуском задайте владельца каталогов: `sudo chown -R 1000:1000 data downloads archive logs`. Пользователь образа по умолчанию — `1000:1000`.

```sh
docker run -d --name media-harbor \
  --restart unless-stopped \
  -p 8080:8080 \
  -v "$PWD/data:/data" \
  -v "$PWD/downloads:/downloads" \
  -v "$PWD/archive:/archive" \
  -v "$PWD/logs:/logs" \
  -e TZ=Asia/Singapore \
  ghcr.io/leapsea/media-harbor:latest
```

Откройте [http://localhost:8080](http://localhost:8080). Пример подключает все каталоги. Если архивирование или сохранение журналов не нужно, удалите соответствующий параметр `-v`.

| Каталог хоста | Содержимое | Обязательно подключать? |
| --- | --- | --- |
| `data` | Задачи, настройки, Cookie и индекс загрузок | Для запуска нет; рекомендуется для сохранения состояния при пересоздании контейнера |
| `downloads` | Скачанные файлы | Для запуска нет; рекомендуется для доступа и сохранения файлов на хосте |
| `archive` | Архивные файлы | Обязательно для архивирования, с правом записи |
| `logs` | Журналы задач | Необязательно; подключите для просмотра и сохранения журналов на хосте |

Без подключения данные находятся внутри контейнера и теряются при его удалении. Для смены порта хоста измените первое число в `-p 8080:8080`, а пути замените своими каталогами.

### Вариант 2: Собрать из исходников

Установите Docker, Compose и Git, затем выполните:

```sh
git clone https://github.com/leapsea/media-harbor.git
cd media-harbor
cp .env.example .env
mkdir -p data logs downloads archive
```

В Linux перед запуском задайте владельца каталогов по `PUID` / `PGID` в `.env`. Для значений по умолчанию выполните `sudo chown -R 1000:1000 data logs downloads archive`. Другой пользователь описан в [документации](docs/部署与开发.md#docker-配置).

```sh
docker compose up -d --build
```

## Первая задача

### Скачать отдельное видео или пост

1. Откройте **Задачи → Новая задача**.
2. Выберите платформу, вставьте адрес контента и проверьте найденное имя папки.
3. Выберите параметры и сохраните. Ссылка на отдельный материал запускается сразу один раз.
4. Следите за прогрессом в задачах. Готовые файлы доступны в истории; кнопка копирования копирует путь к папке.

### Получать новые публикации автора

1. Создайте задачу с адресом профиля, именем папки и интервалом, затем сохраните.
2. Нажмите **Полная инициализация**, чтобы получить доступный контент. Сохранение задачи профиля само по себе загрузку не запускает.
3. После первого ручного запуска включается расписание. Далее в очередь попадает только новый контент; расписание можно приостановить и возобновить.

| Действие | Назначение |
| --- | --- |
| Полная инициализация | Первая загрузка контента профиля |
| Поиск новых материалов | Проверка новых публикаций; подходит и для первого запуска |
| Дозагрузить | Использовать существующие файлы, получить недостающие, обновить выбранные комментарии и метаданные |
| Повторить | Повторный запуск неудачных задач |

Метки истории соответствуют реальным файлам. Комментарии хранятся в JSON метаданных: обе метки относятся к одному файлу. **Очистить историю загрузок** удаляет только записи отображения, сохраняя файлы и индекс; дальнейшие проверки пропускают уже скачанное.

## Основные настройки

Меняйте параметры в **Настройках** и нажимайте **Сохранить настройки**.

| Раздел | Назначение |
| --- | --- |
| Загрузка | Параллелизм платформ и параметры YouTube; задача может переопределить параметры загрузки |
| Правила каталогов | Шаблон, источник даты и архивирование; архиву нужен подключённый каталог с правом записи |
| Cookie | Вставка Cookie браузера в редактор; сохранённые Cookie используются автоматически |
| Интерфейс | Язык, последние загрузки и размер страниц |
| Хранилище | Использованное место, очистка журналов и кэша завершённых или несвязанных задач |
| Отладка | Ограничение небольшой партией; отключение для полной обработки |

Шаблон по умолчанию: `{platform}/{directory_name}/{year}/{month}{day}/{filename}`. Используется дата загрузки/публикации на сайте, а при её отсутствии — дата создания задачи, в локальном часовом поясе.

При запуске готового образа задавайте порт, пути и часовой пояс параметрами запуска; для Compose из исходников — в `.env`. При ошибке доступа смотрите журнал задачи; результат зависит от сети и доступного на платформе контента.
