# Media Harbor

YouTube और Instagram की सामग्री अपने डिवाइस पर डाउनलोड करें, क्रिएटर और तारीख के अनुसार फ़ाइलें व्यवस्थित करें और प्रोफ़ाइल की नई पोस्ट प्राप्त करें।

## सुविधाएँ

- एक वीडियो या पोस्ट डाउनलोड करें, या प्रोफ़ाइल को नियमित अंतराल पर जाँचें।
- YouTube से अधिकतम गुणवत्ता वाला MP4 और अतिरिक्त m4a ऑडियो सहेजें; उपशीर्षक, टिप्पणियाँ, थंबनेल और मेटाडेटा चुनें।
- पहले से डाउनलोड सामग्री छोड़ें। अधूरे डाउनलोड पूरे करते समय मौजूदा फ़ाइलें इस्तेमाल होती हैं, गायब फ़ाइलें मिलती हैं और चुनी हुई टिप्पणियाँ व मेटाडेटा अपडेट होते हैं।
- स्थिति, प्रगति, लॉग और इतिहास देखें; कार्य रद्द करें, दोबारा चलाएँ और पुनः प्रारंभ के बाद जारी रखें।
- फ़ाइलें व्यवस्थित और संग्रहित करें। इंटरफ़ेस चीनी, अंग्रेज़ी, हिन्दी, रूसी और जापानी में उपलब्ध है।

## शुरू करें

### विकल्प 1: इमेज सीधे प्राप्त करें (अनुशंसित)

Docker स्थापित करें; स्रोत डाउनलोड करने की आवश्यकता नहीं है। इमेज पहली बार प्रकाशित होने के बाद चलाएँ:

```sh
docker pull ghcr.io/leapsea/media-harbor:latest
mkdir -p data downloads archive logs
```

Linux पर कंटेनर शुरू करने से पहले फ़ोल्डर का मालिक सेट करें: `sudo chown -R 1000:1000 data downloads archive logs`। इमेज का डिफ़ॉल्ट उपयोगकर्ता `1000:1000` है।

```sh
docker run -d --name media-harbor \
  --restart unless-stopped \
  -p 8080:8080 \
  -v "$PWD/data:/data" \
  -v "$PWD/downloads:/downloads" \
  -v "$PWD/archive:/archive" \
  -v "$PWD/logs:/logs" \
  -e TZ=Asia/Singapore \
  ghcr.io/leapsea/media-harbor:latest
```

[http://localhost:8080](http://localhost:8080) खोलें। उदाहरण सभी फ़ोल्डर माउंट करता है। संग्रह या लॉग सहेजना आवश्यक न हो तो संबंधित `-v` विकल्प हटाएँ।

| होस्ट फ़ोल्डर | सामग्री | माउंट आवश्यक है? |
| --- | --- | --- |
| `data` | कार्य, सेटिंग, Cookie और डाउनलोड इंडेक्स | शुरू करने के लिए नहीं; कंटेनर दोबारा बनाने पर स्थिति रखने के लिए अनुशंसित |
| `downloads` | डाउनलोड फ़ाइलें | शुरू करने के लिए नहीं; होस्ट पर फ़ाइलें पाने और रखने के लिए अनुशंसित |
| `archive` | संग्रहित फ़ाइलें | संग्रह सक्षम करने के लिए लिखने योग्य माउंट आवश्यक |
| `logs` | कार्य लॉग | वैकल्पिक; होस्ट पर लॉग देखने और रखने के लिए माउंट करें |

बिना माउंट का डेटा कंटेनर के भीतर रहता है और कंटेनर हटाने पर मिट जाता है। होस्ट पोर्ट बदलने के लिए `-p 8080:8080` का पहला पोर्ट बदलें और अपने संग्रहण पथ इस्तेमाल करें।

### विकल्प 2: स्रोत प्राप्त करके बिल्ड करें

Docker, Compose और Git स्थापित करके चलाएँ:

```sh
git clone https://github.com/leapsea/media-harbor.git
cd media-harbor
cp .env.example .env
mkdir -p data logs downloads archive
```

Linux पर शुरू करने से पहले `.env` के `PUID` / `PGID` के अनुसार फ़ोल्डर का मालिक सेट करें। डिफ़ॉल्ट के लिए `sudo chown -R 1000:1000 data logs downloads archive` चलाएँ। अलग उपयोगकर्ता के लिए [तैनाती दस्तावेज़](docs/部署与开发.md#docker-配置) देखें।

```sh
docker compose up -d --build
```

## पहला कार्य बनाएँ

### एक वीडियो या पोस्ट डाउनलोड करें

1. **कार्य प्रबंधन → नया कार्य** खोलें।
2. प्लेटफ़ॉर्म चुनें, सामग्री का URL पेस्ट करें और पहचाना गया फ़ोल्डर नाम जाँचें।
3. डाउनलोड विकल्प चुनकर सहेजें। किसी विशिष्ट सामग्री का URL तुरंत एक बार चलता है।
4. कार्य में प्रगति और डाउनलोड इतिहास में फ़ाइलें देखें। कॉपी बटन से फ़ोल्डर का पथ प्राप्त करें।

### क्रिएटर की प्रोफ़ाइल के लिए नियमित डाउनलोड

1. प्रोफ़ाइल URL, फ़ोल्डर नाम और अंतराल के साथ कार्य बनाएँ और सहेजें।
2. **पूर्ण आरंभिक स्कैन** से उपलब्ध सामग्री डाउनलोड करें। केवल प्रोफ़ाइल कार्य सहेजने से डाउनलोड शुरू नहीं होता।
3. पहले मैन्युअल रन के बाद नियमित जाँच शुरू होती है। आगे केवल नई सामग्री कतार में जुड़ती है; समय-सारणी रोक या फिर चालू कर सकते हैं।

| कार्रवाई | उपयोग |
| --- | --- |
| पूर्ण आरंभिक स्कैन | पहली बार प्रोफ़ाइल की सामग्री प्राप्त करना |
| नई सामग्री खोजें | नई सामग्री जाँचना; पहली बार भी उपयोग कर सकते हैं |
| अधूरे डाउनलोड पूरे करें | मौजूदा फ़ाइलें इस्तेमाल करना, गायब फ़ाइलें लाना और चुनी हुई टिप्पणियाँ व मेटाडेटा अपडेट करना |
| पुनः प्रयास | विफल कार्य फिर चलाना |

इतिहास के टैग वास्तविक फ़ाइलों से जुड़े हैं। टिप्पणियाँ मेटाडेटा JSON में रहती हैं और उसी फ़ाइल पर दोनों टैग दिखते हैं। **डाउनलोड इतिहास साफ़ करें** केवल दिखने वाले रिकॉर्ड हटाता है; फ़ाइलें और इंडेक्स बने रहते हैं, इसलिए आगे पुराने डाउनलोड छोड़े जाते हैं।

## सामान्य सेटिंग

**सेटिंग** में बदलाव के बाद **सेटिंग सहेजें** चुनें।

| भाग | उपयोग |
| --- | --- |
| डाउनलोड | प्लेटफ़ॉर्म समवर्ती डाउनलोड और YouTube के डिफ़ॉल्ट विकल्प; कार्य में अलग विकल्प चुन सकते हैं |
| फ़ोल्डर नियम | फ़ोल्डर टेम्पलेट, तारीख और संग्रह; संग्रह के लिए लिखने योग्य माउंट चाहिए |
| Cookie | संपादक में ब्राउज़र Cookie पेस्ट करें; सहेजे Cookie अपने आप उपयोग होते हैं |
| इंटरफ़ेस | भाषा, हाल के डाउनलोड और प्रति पृष्ठ संख्या |
| स्टोरेज | स्थान उपयोग, लॉग हटाना और पूरे या असंबद्ध कार्यों का कैश साफ़ करना |
| डिबग | छोटे बैच के लिए सीमा लगाएँ; पूरी सामग्री के लिए बंद करें |

डिफ़ॉल्ट नियम `{platform}/{directory_name}/{year}/{month}{day}/{filename}` है। वेबसाइट की अपलोड/प्रकाशन तारीख उपलब्ध हो तो उसका उपयोग होता है, अन्यथा कार्य बनने की तारीख का; समय क्षेत्र स्थानीय है।

सीधे इमेज चलाते समय पोर्ट, पथ और समय क्षेत्र रन विकल्पों में बदलें; स्रोत वाले Compose के लिए `.env` बदलें। प्लेटफ़ॉर्म तक पहुँच विफल हो तो कार्य लॉग देखें; परिणाम नेटवर्क और प्लेटफ़ॉर्म पर उपलब्ध सामग्री पर निर्भर हैं।
